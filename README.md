# Manggo 免费服务包

为 Manggo 提供免配置的翻译服务，以及需要个人账号的白描 OCR 服务。

## 服务

| 服务 | 类型 | 说明 |
| --- | --- | --- |
| 腾讯交互翻译 | 翻译 | 使用腾讯交互翻译网页接口 |
| 火山翻译 | 翻译 | 使用火山翻译浏览器扩展接口 |
| 有道翻译 | 翻译 / 词典 | 单词优先返回词典结果，其他内容返回文本译文 |
| Bing 翻译 | 翻译 | 使用 Microsoft Edge `translatetext` 接口 |
| Google 翻译 | 翻译 | 使用 Google Translate 网页接口 |
| 白描 OCR | 图片文字识别 | 使用白描网页接口，自动识别图片中的文字 |

安装 `.mplugin` 后，在 Manggo 对应的服务设置页面添加所需服务。翻译服务无需配置。白描 OCR 需要在其服务配置中填写白描账号的手机号或邮箱及密码，并受到白描账号的识别额度限制。

这些服务依赖网页接口，可能受到上游限流、地区网络或接口变更影响。
